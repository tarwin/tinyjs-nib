# Lantern

Lantern turns a folder of photos and Markdown notes into a quiet, fast photo journal: one page per trip, a map of where you've been, and nothing that tracks your readers.

```sh
npm create lantern@latest my-journal
cd my-journal && npm run dev
```

The documentation lives in [`docs/`](docs/index.md) and is published at lantern.example.

## Contributing

Issues and pull requests are welcome. Run `npm test` before you send one, and add a line to the [changelog](docs/changelog.md).
