# Command line

| Command                  | What it does                                |
| ------------------------ | ------------------------------------------- |
| `lantern dev`            | Serves the journal and rebuilds on save     |
| `lantern build`          | Writes the finished site to `dist/`         |
| `lantern import <dir>`   | Makes a trip page from a folder of photos   |
| `lantern places --fresh` | Looks every place up again                  |

All commands read [lantern.config.js](config.md) from the current folder.
