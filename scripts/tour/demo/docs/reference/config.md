# lantern.config.js

```js
export default {
  title: 'Our travels',
  theme: 'harbour',
  map: { style: 'quiet', zoom: 4 },
  photos: { width: 1600, quality: 80 },
};
```

## Options

- `title` — the journal's name, on every page.
- `theme` — see [Themes](../guide/themes.md#your-own-colours).
- `map` — the map's style and starting zoom.
- `photos` — the size and quality of the web copies.
