# Keyboard shortcuts

These are the default keys on macOS. On Windows and Linux, use <kbd>Ctrl</kbd> for <kbd>⌘</kbd>, <kbd>Alt</kbd> for <kbd>⌥</kbd> and <kbd>Shift</kbd> for <kbd>⇧</kbd>. You can change any menu shortcut in [Settings ▸ Shortcuts](./settings#shortcuts).

On Windows and Linux the Welcome window has no menu bar, but its shortcuts still work. The **Command Palette** (<kbd>⌘</kbd><kbd>⇧</kbd><kbd>P</kbd>) runs any menu item by name, on every system.
